# Brand asset provenance

The raster files in this directory were generated specifically for HS Offline
Tracker from original prompts and then selected and integrated for this
interface. They are not extracted from Hero Siege or copied from HS Tracker.

- `obsidian-arcane-bg.png` — original obsidian/arcane dashboard backdrop
- `app-icon.png` — original application-icon master
- `app-mark.png` — resized application mark derived from the icon master

All remaining interface marks, frames, buttons and status glyphs are authored
as SVG data in `src/skin.svelte.js`. Default alert audio combines
project-generated rarity sounds with processed CC0 utility sounds, documented
in `src/assets/sounds/SOURCES.md`.
